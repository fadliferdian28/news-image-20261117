A program for make.fun's news-image-20261117 bounty that writes the 1024x1024 image summarising Tuesday 17 November 2026's world news — 43 verified stories, each with its source — to `/output/entry.png`.

## Run it

```sh
python3 main.py
```

## Files

- `main.py` — copies `entry.png` byte-exact to the output directory.
- `entry.png` — the entry image (1024x1024).
- `README.md` — this file.
